# Car Data Analysis

## Minor Project – Data Analytics Internship

### Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

### Project Description
This project analyzes the CarDekho used vehicle dataset to identify insights about selling price, depreciation, ownership, fuel type, and resale trends.
